# Funngro Website Concept

A responsive, multi-page website concept inspired by the idea of connecting brands with young talent and helping students develop practical skills through projects.

## 🌐 Live Demo

https://ritesh10101999.github.io/funngro-website/

## ✨ Features

- Modern, dark-themed user interface
- Responsive design for desktop and mobile devices
- Dedicated pages for companies and teens
- Creative content, youth insights, and product discovery sections
- Basic SEO resources, including `robots.txt` and `sitemap.xml`

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

## 📁 Project Structure

- `index.html` — Homepage
- `company.html` — Company-focused page
- `teens.html` — Teens and students page
- `seo-audit.html` — SEO audit page
- `assets/styles.css` — Website styling
- `robots.txt` — Search engine crawling instructions
- `sitemap.xml` — Sitemap for search engines

## 🚀 Deployment

This project is hosted using GitHub Pages.

To view the website, visit the live demo link above.
